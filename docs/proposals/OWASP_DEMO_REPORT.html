Check Finding Details Compliance Severity Status
OW-01 Prompt-Attack Filter Strong
Guardrail 'prod-guardrail' has PROMPT_ATTACK filter at HIGH strength on both input and output.
 No action required. LLM01 full Info Passed
OW-03 PII Redaction Incomplete
Guardrail 'prod-guardrail' has piiEntities configured but is missing baseline CREDIT_DEBIT_CARD_NUMBER.
 Add BLOCK or ANONYMIZE entries for the missing PII types: CREDIT_DEBIT_CARD_NUMBER. LLM02 full Medium Failed
OW-04 Invocation Log Retention Insufficient
Bedrock invocation logs go to CloudWatch log group '/aws/bedrock/invocations' — retention is 7 days (< 30 minimum).
 Set CloudWatch log group retention to at least 30 days via PutRetentionPolicy. LLM02 partial-app-layer Medium Failed
OW-09 Action Group Has Wildcard Permissions: OrderBot/PlaceOrder
Action group 'PlaceOrder' on agent 'OrderBot' runs Lambda role 'PlaceOrderRole' which has 's3:*' on '*'. Excessive Agency risk under OWASP LLM06.
 Rewrite inline policies to scope s3 actions to the specific order buckets required. LLM06 full High Failed
OW-15 Detective Consumption Controls Present
After-the-fact cost / rate monitoring for Bedrock or SageMaker is configured: 1 CloudWatch alarm(s): BedrockInvocationSpike.
 No action required. LLM10 partial-app-layer Info Passed
OW-17 KB Retrieval Policy Missing: SupportKB
KB 'SupportKB' has no resource-based policy. Any principal with bedrock-agent:Retrieve can query it — direct RAG disclosure risk.
 Attach a resource-based policy restricting Retrieve / RetrieveAndGenerate to specific IAM principals. LLM02 full High Failed
